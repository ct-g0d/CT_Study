# Planner (CT_Study)

A comprehensive personal study, productivity, and warplan desktop suite built with Vite, TypeScript, and Tauri.

## Features
- Native window chrome and fluid desktop animations
- Integrated study tracking, curriculum mapping, and warplan synchronization
- Offline-first SQLite persistence and automated test suites

## Development
```bash
pnpm install
pnpm dev
pnpm test
pnpm build
```
